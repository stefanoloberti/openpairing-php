# Code of conduct

Participants must be respectful, constructive, and welcoming. Harassment,
discrimination, threats, publication of private information, and bad-faith
disruption are unacceptable. Technical disagreement should focus on evidence,
reproducible cases, published rules, and documented trade-offs.

Maintainers may edit or remove inappropriate contributions and restrict
participation when necessary. Enforcement contact details will be added before
the project is published; until then this repository remains local.
